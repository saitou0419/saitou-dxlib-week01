# saitou-dxlib-week01
Ghost Scoop - Personal Project in C++

##概要

　障害物を避けながら走る×撮影を組み合わせたシンプルな２Ｄランニングゲームです。

##操作方法

 ジャンプ  :space
 
 　　撮影　：sキー
   
 タイトル　：Tキー
 
##制作期間

　約１か月半
 
##使用技術

　ｃ＋＋　/  DxLib  

##工夫した点

　ゲームが単調にならいなように、一定数のゴースト撮影でフラッシュ演出や速度・フィールド変化を実装しました。

  ・撮影要素をもっと工夫して、面白さを向上させたい。
